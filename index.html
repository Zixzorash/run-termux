1นำเข้าโปรเจกต์

ยังไม่ได้เลือกโปรเจกต์

2ตั้งค่าแอป

ใช้ GEMINI_API_KEY จาก GitHub Secret ตอน build

3สร้างชุด Build Kit

4Build บน GitHub Actions (ฟรี)

  1. สร้าง repo ใหม่บน GitHub (Private ก็ได้)
  2. Add file → Create new file ตั้งชื่อ .github/workflows/build-apk.yml → วาง Workflow (ปุ่มด้านล่าง) → Commit
  3. ถ้าใช้ Gemini: Settings → Secrets and variables → Actions → เพิ่ม GEMINI_API_KEY
  4. Add file → Upload files → เลือก ไฟล์ ZIP ต้นฉบับ ไฟล์เดียว (ไม่ต้องแตก) → Commit ระบบจะ build อัตโนมัติ
  5. แท็บ Actions → รอ ~5–10 นาที → เปิด run ล่าสุด → โหลด app-debug-apk ที่ Artifacts → ติดตั้งบน Xiaomi
วิธีนี้ไม่ต้องใช้ Build Kit — ปุ่มสร้าง Kit ด้านบนเป็นทางเลือกเท่านั้น


⚠️ API key ที่ฝังใน APK ดึงออกได้ ควรจำกัดโควต้า/ใช้ proxy ถ้าจะเผยแพร่จริง
