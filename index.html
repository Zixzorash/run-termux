Build APK
By IDOL_CHAMP

แปลงแอปจาก Google AI Studio เป็น APK · ใช้บนมือถือล้วน ไม่ต้อง Root

1นำเข้าโปรเจกต์

ยังไม่ได้เลือกโปรเจกต์

2ตั้งค่าแอป

ใช้ GEMINI_API_KEY จาก GitHub Secret ตอน build

3สร้างชุด Build Kit

4Build บน GitHub Actions (ฟรี)

  1. สร้าง repo ใหม่บน GitHub (Private ก็ได้) แล้วอัปโหลดไฟล์จาก Build Kit (แตก zip ก่อน)
  2. ถ้าใช้ Gemini: Settings → Secrets → Actions → เพิ่ม GEMINI_API_KEY
  3. แท็บ Actions → Build APK → Run workflow
  4. รอ ~5–8 นาที → โหลด app-debug.apk จาก Artifacts → ติดตั้งบน Xiaomi (อนุญาต “ติดตั้งแอปที่ไม่รู้จัก”)
มี repo อยู่แล้ว? คัดลอกเฉพาะไฟล์ workflow ไปวางที่ .github/workflows/build-apk.yml


⚠️ API key ที่ฝังใน APK ดึงออกได้ ควรจำกัดโควต้า/ใช้ proxy ถ้าจะเผยแพร่จริง
